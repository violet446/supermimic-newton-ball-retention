## 记录与动量平衡

所有接触记录中铲为形状 0，球为形状 1。将公开的铲侧受力反号后积分得到球的线冲量。球侧角冲量从 XPBD 对球实际施加的修正量独立读取。每个子步同时核对实测速度和角速度变化。

| 核对量 | 768 子步的最大残差 | 冻结阈值 |
| --- | ---: | ---: |
| 接触力积分与求解器线冲量 | 4.84e−10 N·s | 1e−7 N·s |
| 扣除重力后的线速度变化 | 3.00e−8 m/s | 1.5e−4 m/s |
| 角速度变化 | 3.06e−6 rad/s | 1.5e−4 rad/s |

正负分支每子步分别记录 1–7 个和 1–6 个非零接触冲量，以向量范数大于 1e−12 N·s 计。[正分支逐接触记录](pitch_pulse_plus.json) · [负分支逐接触记录](pitch_pulse_minus.json)

## H8–H24 的速度半差

先按求解器提供的各接触点法向拆分冲量，再将两类冲量投到各分支控制周期起点的局部网格切平面。由此得到法向和切向冲量各自在实测切向速度响应上的带符号投影比例。周期结果对 16 个子步向量先求和，再跨周期计算比例。

| 统计粒度 | 接触法向冲量 | 接触切向冲量 | 用单网格法向从自转反推切向的余弦 | 按各接触法向重构球侧角冲量的相对 RMS |
| --- | ---: | ---: | ---: | ---: |
| 物理子步 | +112.64% | −12.64% | −0.472 | 0.125% |
| 控制周期 | +124.48% | −24.48% | −0.963 | 0.109% |

两类冲量相加对实测切向半差的重构误差为子步 0.0055%、控制周期 0.0032%。法向项超过 100% 由切向冲量的反向贡献抵消。独立复算将控制周期的 +124.48% 再分为投影后合冲量方向差 +125.31%、合冲量大小差 −0.83%。这里的方向差包含各分支各自切平面投影的影响。[动量与分解](momentum.json) · [独立复算](independent_check.json)

本快照上，单一网格法向的反推偏差在物理子步就已出现，聚合到控制周期后方向偏差更强。逐接触法向和球半径力臂能够闭合球侧角冲量。结果限于原开发快照的短俯仰动作及当前接触配置。
