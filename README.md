# Newton 单球保料世界模型

这是为后续 SuperMimic 训练准备世界模型的单球实验。Newton 仿真中，机械臂用铲子托住一颗球，4 秒内横移 8 厘米。控制可以微调铲子的横滚和俯仰，最终用是否走完路线、球是否留在铲上来验收。

## “预测半秒”怎么测

仿真每秒有 60 个控制周期。取某一刻的实测位置、速度、自转和铲子状态，给模型接下来 32 个周期的动作序列。模型每一步都基于自己的上一步预测，再把第 32 步与 Newton 同起点、同动作的实测比较。32 ÷ 60 ≈ 0.53 秒是仿真里的时间跨度。对小动作的评分还会给两边相反的动作，看模型是否判断对变化的方向和大小。

目前加普通轨迹能改善普通路线上的位置预测，开发快照上的小动作响应仍有方向和幅值误差。希望听取的建议是，怎样设定启动 SuperMimic 的最低可靠性门槛，以及是否可以先用更短的预测时长做一次小规模验证。
