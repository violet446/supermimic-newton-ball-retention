# S3 后半段单步监督标签与方向覆盖

重评加入两项单步监督前后的两个固定 900 更新终点。训练侧为两个 `reverse` 和一个 `advance` 快照，每个快照三对。开发侧为 `validation_lateral` tick 168 的三对。训练和开发使用相同的三条扰动序列与 0.20 幅度，各自叠加在所在快照的名义动作上。逐值复现开发轨迹和评分，核对十二对的既有 H8–H24 独立单步得分、训练侧 H1–H16 掩码与加权半差 RMSE。单线程 CPU 约 2.43 秒，峰值工作集约 109 MiB。训练 0 更新、仿真 0 步，测试轨迹封存。[运行验收](validation.json) · [逐步向量与结果](late_coverage.json)

## 标签强度与方向覆盖

标签为正负动作分支的世界系非重力速度增量差的一半。可辨门槛取 0.01 mm/s 与同快照名义重复半差的五倍之较大者。强信号门槛为其十倍。训练和开发的名义重复半差均为零。训练 H1–H16 的 144 步全部可辨，其中 95 个强信号；H17–H32 同样全部可辨，其中 138 个强信号。

方向覆盖只对开发快照的强信号逐步计数。对同一动作、同一步，将开发的 Newton 标签与各训练快照的 Newton 标签求方向余弦，至少 0.8 视为相近。括号内为至少两个训练快照方向相近的步数。

| 动作 | H1–H16 | H17–H32 |
| --- | ---: | ---: |
| 俯仰短脉冲 | 7/11（3） | 8/14（2） |
| 俯仰反向 | 9/12（4） | 5/13（3） |
| 双轴短脉冲 | 5/9（3） | 7/16（1） |

后半段双轴三条训练轨迹全有强信号，但开发 H20 和 H22 的方向与三个训练快照都成钝角。俯仰反向 H19 的三个余弦约为 −0.94、−0.97 和 −0.99。双轴后段方向相近的训练标签，其幅值中位数约为开发同一步的 0.55 倍；俯仰反向约为 0.38 倍。这是有限快照下同一步的方向覆盖，结果随真实球状态与接触变化。

## 两个终点的误差

| 独立单步 RMSE（mm/s） | H1–H16，监督前 → 后 | H17–H32，监督前 → 后 |
| --- | ---: | ---: |
| 训练九对合并，增量头 | 0.340 → 0.265 | 2.714 → 2.701 |
| 开发俯仰短脉冲，预测后换算 | 0.508 → 0.475 | 1.452 → 1.432 |
| 开发俯仰反向，预测后换算 | 0.528 → 0.494 | 1.164 → 1.161 |
| 开发双轴短脉冲，预测后换算 | 0.494 → 0.617 | 1.169 → 1.237 |

开发双轴 H17–H32 的单步增量误差投到 Newton 最终位移方向并积分，贡献由 **+0.695 mm** 转为 **−0.920 mm**。三个训练快照上的同项在两个模型中均为负，加入监督后两个快照的负偏差减小，另一个增大。训练侧可复现后段向负方向积累，但未出现开发从正转负这一模式。三对俯仰反向的训练快照上，该投影有正有负。分段积分与上一轮开发逐步分解逐值核对。

等步数合计时，单条 `advance` 双轴配对占九对后半段标签总平方范数的 71.4%。这一比例用来描述标签幅值分布。下一项先在冻结参数上实测延长窗口后的损失与梯度，并核对各快照、动作和时段的贡献，再判断是否启动一轮匹配训练。
