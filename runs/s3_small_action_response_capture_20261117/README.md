## 双轴响应的单轴误差和相互作用

匹配分量的纯横滚、纯俯仰的实测 H32 半差分别为 0.111、0.265 mm。把两条实测半差向量相加，得到 0.173 mm，与实际双轴 0.225 mm 的方向余弦仅 +0.097。双轴减去单轴和之后，剩余向量幅值 **0.270 mm**。这说明叠加的误差不能用两个单轴幅值直接推断。该差在 H10 初次超过三路可辨底之和 0.003 mm，H24 为 0.059 mm。

61 对横滚有限扰动预测与实测大致同向，但幅值达实测的 7.21 倍。沿 61 对预测双轴相对 Newton 的总误差向量，横滚误差、俯仰误差及两轴残差误差分别贡献 **+0.661、+0.123、−0.133 mm**，加总闭合到 0.652 mm。49 对的同一分解为 +0.004、+0.342、+0.105 mm，分别投影到各自的总误差方向。61 对主要偏差来自横滚，Newton 本身的两轴相互作用也需独立建模。[相互作用和误差向量](../s3_small_action_response_audit_20261117/amplitude_and_axis_attribution.json)
