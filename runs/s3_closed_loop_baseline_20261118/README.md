# S3 完整路线的原计划与简单反馈对照

从两个已验收训练初态开始，每个初态使用同一个 Newton 物理配置分别执行两种控制。原计划动作沿规定路线行进，横滚和俯仰修正为零。反馈案前 60 个控制周期相同，满 1 秒后读取当前位置和速度，给出有界倾角修正。两组的零修正前缀均逐字段复现。反馈目标取自 S1 已成功的零倾角完整回合，铲坐标约为 (285.75, −32.50) mm。位置和速度增益预先设为 8 m⁻¹、3 s/m，每轴请求上限 0.12，对应 0.6° 目标增量。继续使用原滤波和执行边界。符号、限幅以及名义、四角和切换指令全部静态核查通过。见 [冻结输入](preflight.json)。

## 硬结果和球位置

四个有效回合均完成 240 个控制周期、4 秒和约 80 mm 位移。四案全程无掉落，末态承载与近接触均通过。路线最大跟踪误差小于 0.60 µm。按既定成功标准，原计划 **2/2**，反馈 **2/2**。球心距目标的指标只使用 1–4 秒的实际 Newton 球状态，采用铲坐标的平面距离。

| 训练初态 | 控制 | 硬验收 | 最后距目标（mm） | 1–4 秒距目标均方根（mm） | 末态平面相对球速（mm/s） |
| --- | --- | --- | ---: | ---: | ---: |
| 中间 | 原计划 | 通过 | 27.71 | 19.29 | 48.60 |
| 中间 | 简单反馈 | 通过 | 18.02 | 18.27 | 49.40 |
| 右侧 | 原计划 | 通过 | 32.46 | 23.15 | 78.93 |
| 右侧 | 简单反馈 | 通过 | 28.75 | 23.10 | 92.70 |

反馈在两个起点把最终球位置拉近目标，分别约 9.69 和 3.71 mm。整个行动阶段的改善较小，且两个反馈回合的最终球速都增加。四案已经保住球，已有比较支持把两种方案作为后续对照和采样行为。保料成功率是否改善、球是否更稳定，还需更多独立工况。见 [完整对照与数据路径](comparison.json) 和 [位置、速度及吞吐复核](route_metrics.json)。

## 资源停止与恢复

第一个原计划回合完整保留。中间反馈回合因系统可用 RAM 低于 0.75 GiB 两次停止，分别保留 10 和 76 条记录。两次之间另有一个启动准入拒绝，Newton 0 步。首条部分轨迹与原计划的相同时间前缀逐字段一致。第二条部分轨迹的 76 条动作及关节命令在 CPU 上复现。按用户批准范围，从第 75 周期的公开球、工具与控制状态重建两个 Newton 缓冲。第 76 周期重跑后完整转移逐字段相同，随后完成第 77–240 周期。正式反馈轨迹合并原先 76 条归档与新尾段，验证周期未重复入档。见 [首次停止](stopped.json)、[第二次停止](continuation/stopped.json)、[恢复清单](restored_completion_plan.json) 和 [第 76 周期核对](restored_completion/broad_train_72_center_feedback/worker/verification_cycle.json)。

四条有效轨迹共 960 条控制转移、15,360 个物理子步。含中断与恢复复核，已知执行 15,536 个子步，两次各可能另有 16 个未写入子步，累计保守上界 15,568。所有受控运行阶段合计约 675 秒，训练 0 更新，测试封存，主模型保留。见 [采集验收](validation.json)。

## 批量采集测算

三个单次跑完的回合平均 **1.63 条控制转移/秒**，约 26.09 Newton 子步/秒。控制循环共 441.56 秒，环境步进占 440.46 秒，包含控制规划、Newton 与状态检查。普通轨迹的 JSON 编码和写入合计 0.22 秒。在当前串行调用方式下，减少输出字段对总时间的影响有限。四条有效 JSONL 约 7.94 MB。按三个完整回合的循环速度粗估，一百万控制转移约需 170 小时，尚未计启动及中断。12 个完整回合能增加 2,880 条普通连续转移，串行控制循环约 29.4 分钟。另有一个恢复尾段，速度约 1.58 条/秒，已分开记录。见 [采集实测与估算](route_metrics.json)。
