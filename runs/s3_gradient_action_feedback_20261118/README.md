# S3 两案小动作轨迹误差分解

冻结原 61 对模型的第 900 次更新，逐项复现两案八条轨迹的 Newton 评分和模型原先的 H32 预测。Hn 表示自快照起第 n 个控制周期。名义取两条相同名义轨迹的均值。共同偏移是建议与反向分支的均值减名义。正反半差是建议减反向再除以二。两项相加等于建议减名义。本轮训练 0 更新，Newton 仿真 0 步，测试封存。[验收](validation.json) · [逐步轨迹与分解矩阵](feedback_decomposition.json)

## 第一案的持续转折

第一案 `validation_lateral` 在 H20 的建议动作仍比名义少偏 0.01096 mm。H21 起到 H32，两条扰动共同向外多偏，幅值持续大于正反半差。建议动作在 H22 起持续比名义多偏超过 0.010 mm。第二案没有持续到 H32 的同类退步。

| 第一案 | Newton 共同偏移（mm） | Newton 正反半差（mm） | Newton 建议减名义（mm） | 模型建议减名义（mm） |

| H20 | +0.02081 | −0.00985 | +0.01096 | +0.07940 |
| H21 | −0.00870 | +0.00510 | −0.00359 | +0.09019 |
| H22 | −0.01926 | +0.00401 | −0.01525 | +0.10163 |

表中各轨迹从 H20 起都向负 y 偏移，正的位置改变量表示更靠近起始横向坐标。第二案 H32 的共同偏移为 +0.00385 mm，正反半差为 +0.06718 mm，合计改善 +0.07103 mm。第一案的退步来自共同向外偏移，第二案的改善主要来自随动作符号改变的响应。

## 单步误差与连续预测

在各分支自己的工具坐标变换下，逐步反算恰好能复现 Newton 下一速度的世界系增量。将模型在**实测步前状态**上的增量误差逐步向后传播，得到独立单步项。将同一模型由实测输入切换到它自己预测的步前状态，由此产生的增量变化记为滚动反馈项。再单独传播模型位置积分规则与 Newton 的差。三项逐步加总复现每条分支及其各种组合的误差，自由滚动只使用模型自己的前一步预测。

| 工况与 H32 指标 | 模型减实测（mm） | 独立单步（mm） | 滚动反馈（mm） | 位置积分（mm） |
| --- | ---: | ---: | ---: | ---: |
| 第一案·建议减名义 | +0.33741 | +0.48917 | −0.11686 | −0.03490 |
| 第一案·共同偏移 | +0.09638 | +0.28653 | −0.15995 | −0.03021 |
| 第一案·正反半差 | +0.24103 | +0.20264 | +0.04308 | −0.00470 |
| 第二案·建议减名义 | +0.10092 | +0.12069 | −0.01697 | −0.00280 |

第一案的建议动作误差主要来自独立单步预测，滚动反馈抵消了部分误差。按误差产生的周期分段，H17–H24 对最终建议误差贡献 +0.23176 mm，约占总有符号误差的 69%。同一时段给共同偏移的独立单步误差贡献 +0.27370 mm，其中 H20–H22 合计 +0.26581 mm。第一案的正反半差高估还包含较早 H9–H16 的独立单步误差 +0.19146 mm。第二案也高估改善，但 H17–H24 对建议误差的净贡献仅 +0.04246 mm。

这个分解归因到模型的速度增量、步前输入和位置积分。某个误差时段是否对应接触冲量变化，需要另用已有接触与训练归档核对。分支位置与速度的逐步加总最大残差为 1.56e−16（米或米每秒）。单线程 CPU 用时 2.32 秒，峰值工作集 106.38 MiB，输出约 0.92 MiB。[执行计划](execution_plan.json) · 资源记录（本地归档）
