# S3 以 Newton 为参照的俯仰增量误差

固定前段与全段监督两个终点，复现 `validation_lateral` tick 168 的俯仰轨迹、评分和动作导数。把 Newton 的步前球状态和实测下一步工具系速度代入模型的解析工具变换，反算该步所需的世界系速度增量。将模型的增量误差和梯形积分相对 Newton 的位置离散差分别传播到 H32。两模型的逐步误差及原检查点之差都闭合。反算下一步速度的最大分量误差为 1.73e−18 m/s，传播闭合误差约为 1.60e−16 SI。训练 0 更新、仿真 0 步，测试封存。[验收](validation.json) · [逐步数据](newton_reference.json)

列按误差的生成步分组，每列均报告它传到 H32 后的贡献。两种俯仰共同的 H8 位置误差范数从 0.0930 降到 0.0324 mm。前八步原有同向过响应被明显压小，两个模型在两种动作中最大的负向误差来源都是 H9–H16。全段短脉冲中，H9–H16 的 −0.561 mm 由共用 Newton 步前状态时的独立单步误差 −0.473、滚动输入额外变化 −0.090 和位置离散差 +0.002 mm 组成。全段俯仰反向对应 −0.737、−0.386 和 +0.007 mm。

整段位置离散差投影为短脉冲 −0.00979 mm、俯仰反向 +0.00359 mm。两组反算世界增量半差与直接归档的相应 RMSE 分别为 5.69e−5 和 6.70e−5 mm/s。下一步实际完成了两训练组之间的 H9–H16 误差迁移核查。[留组结果](../s3_world_increment_pitch_transfer_20261117/README.md)
