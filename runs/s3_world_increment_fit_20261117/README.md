# S3 世界系速度残差匹配拟合

固定 49 对、900 更新，复现原参考的开发评分和 S2 抽样 SHA256。训练使用原 S2 与配对损失、权重和 Adam。网络维度及初始参数逐项一致。候选由解析坐标更新处理工具运动和重力，网络输出世界系速度残差，固定输出中心来自九对训练样本的 576 个完整步。两种结构的零输出动力学基线因解析更新而不同。训练前检查合并损失梯度，训练后重载检查点并复核三种动作的方向导数。仿真 0 步，测试轨迹封存。[执行方案](execution_plan.json) · [训练入口预检](fit_preflight.json) · [验收](validation.json)
