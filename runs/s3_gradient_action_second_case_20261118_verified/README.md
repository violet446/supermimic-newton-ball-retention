## 为什么两案的排序不同

在第 32 步，名义和两侧扰动都向负 y 偏移。下面按带符号的位置分解相对名义的变化。把两条扰动分支取平均再减名义，得到两侧共同的位置变化。建议分支减反向分支后除以二，得到随扰动符号改变的位置变化。两项相加是建议动作相对名义的位移。正号在这两案都表示球更接近横向起点。

| 工况 | 模型共同变化（mm） | 实测共同变化（mm） | 模型正反半差（mm） | 实测正反半差（mm） |
| --- | ---: | ---: | ---: | ---: |
| `validation_lateral` | −0.02722 | −0.12359 | +0.25433 | +0.01330 |
| `history_validation_yplus006_reverse` | +0.03746 | +0.00385 | +0.13449 | +0.06718 |

第一案两侧共同的负向变化大于正反半差，建议动作因而比名义多偏。第二案的改善主要来自正反半差。这个分解描述轨迹结果，变化来自哪些时段和动力学误差仍待离线核查。
