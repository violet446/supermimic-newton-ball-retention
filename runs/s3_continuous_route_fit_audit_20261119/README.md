# S3 普通轨迹拟合的固定终点诊断

从原 61 对、6 回合档和 12 回合档的第 900 次检查点复现冻结开发快照的原幅和小幅评分。诊断使用两条名义、原幅俯仰反向正负、纯横滚正负六条 Newton 归档。六条轨迹的输入重建不使用未来球状态，归档未来状态只用于评分及单步误差诊断。固定参数在诊断前后哈希一致。本轮训练 0 更新、仿真 0 步，测试封存，主模型保留。[执行清单](execution_plan.json) · [验收](validation.json)

## 单步误差与连续预测

每个控制周期用实测的步前状态起算，得到独立单步误差。把步前状态换成模型自身的上一步预测，得到预测反馈额外引入的速度增量误差。两部分各自向后传播，再加上位置积分规则与 Newton 的差，逐步复现位置和速度误差。三检查点最大闭合差为 2.66e−15（米或米每秒）。表中分解项是对 H32 误差长度变化的有符号贡献，负数抵消退步。位置积分规则在这些检查点间相同，其项相减为零。

| H32 指标 | 原 61 对 → 6 回合 → 12 回合（mm） | 6 回合单步 / 反馈（mm） | 12 回合单步 / 反馈（mm） |
| --- | ---: | ---: | ---: |
| 名义位置漂移 | 4.310 → 9.293 → 9.213 | +0.790 / +4.193 | +0.339 / +4.564 |
| 原幅俯仰反向位置半差误差 | 0.072 → 0.507 → 0.542 | −0.209 / +0.644 | −0.253 / +0.722 |
| 纯横滚位置半差幅值 | 0.797 → 1.666 → 1.661 | −0.105 / +0.974 | −0.066 / +0.931 |

俯仰反向与纯横滚的反馈退步主要在第 9–16 步生成。12 回合档中，这 8 步分别给期末反向俯仰误差和横滚幅值增加 +1.094 与 +0.723 mm，其他步有抵消。名义漂移的反馈增长主要来自第 9–24 步。12 回合档名义单步世界速度增量误差的均方根在 H1–H16 从 8.05 降至 7.96 mm/s，在 H17–H32 从 5.02 升至 6.03 mm/s。表中单步来源是面向 H32 的带符号位置贡献，包含各步传播及抵消。[逐步误差与传播分解](trajectory_audit.json)

## 新增训练目标的梯度

将模型固定在原 61 对的第 900 次参数，逐批复用两档真实训练使用的 900 批窗口和对应 S2 抽样。动作响应目标合计配对滚动半差项与单步半差辅助项。用原权重拆开绝对轨迹、配对响应、名义及半差单步项，加回 S2 后复现原联合梯度，最大闭合差 2.78e−17。

| 梯度指标 | 6 回合 | 12 回合 |
| --- | ---: | ---: |
| 新增梯度与合计动作响应梯度方向相逆 | 666/900 | 642/900 |
| 方向余弦中位数 | −0.0229 | −0.0188 |
| 新增梯度范数相对原联合梯度，中位数 | 3.26 倍 | 3.24 倍 |
| 加入新项后，沿梯度下降时的动作响应下降投影相对原值，中位数 | 92.3% | 93.9% |
| 原联合梯度对动作响应的一阶下降被翻成上升 | 0/900 | 0/900 |

新增梯度经常有小的反向分量，范数较大。两档加权梯度合并后，在这里检查的批次仍全都保留动作响应目标的一阶下降方向。这个测量限于固定参数处的原始梯度，Adam 的历史状态和实际训练路径未参与。轨迹分解定位到了滚动反馈，梯度结果不足以把退步归结为动作响应损失被完全抵消。[逐批投影及各项梯度](training_gradient_audit.json)
