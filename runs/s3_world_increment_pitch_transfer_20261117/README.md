# S3 俯仰 H9–H16 两训练组间的迁移

使用三个已归档训练快照和一个冻结开发快照，评估两种俯仰动作和两套固定模型。正 y 训练组含 `reverse` 和 `advance` 两个快照，负 y 训练组含一个 `reverse` 快照。复现开发 H9–H16 单步与自由滚动误差分量。训练 0 更新、仿真 0 步，测试封存。[验收](validation.json) · [各快照结果](pitch_transfer.json)

把 H9–H16 每一步的世界系单步半差误差按原解析工具变换传播到 H32。开发短脉冲的参考增量对 H32 的贡献方向与三训练快照都相近，方向余弦为 0.990–1.000。俯仰反向为 0.655–0.992。这里比较的是整个窗口累积到 H32 的向量，逐步方向覆盖另有独立报告。全段模型的俯仰反向独立单步误差向量，与开发快照的余弦在两个训练快照为 +0.976、+0.806，Advance 为 −0.692。目标响应方向相近时，模型误差仍可能随状态和历史改变。[逐步方向覆盖](../s3_world_increment_late_coverage_20261117/README.md)

将一组训练样本的逐步半差误差取反并平均，构成该组的固定增量修正。只把修正应用到另一组的 H9–H16，各自下游网络增量维持原轨迹记录值，复用确定性传播来计算 H32 变化。这是离线迁移诊断。

| 模型和动作 | 留组时 H9–H16 贡献向量误差改善的快照数 | 留组时 H32 位置误差改善的快照数 | 两组等权修正在开发 H32 的误差（mm） |
| --- | ---: | ---: | ---: |
| 前段，短脉冲 | 0/3 | 0/3 | 0.168 → 0.240 |
| 前段，俯仰反向 | 0/3 | 0/3 | 0.335 → 0.307 |
| 全段，短脉冲 | 3/3 | 0/3 | 0.583 → 0.563 |
| 全段，俯仰反向 | 1/3 | 0/3 | 0.732 → 0.535 |

全段短脉冲的三个留组快照中，只看 H9–H16 来源的误差都减小，但 H32 总误差都增大。说明纠正某个来源时段仍需核对整条轨迹的误差抵消。两个训练组的固定修正没有表现出跨组的终点收益。开发快照的单次改善仅作为对照。下一项用归档接触、状态与执行工具特征检查 H9–H16 的覆盖，先定位适合分开的状态条件。
