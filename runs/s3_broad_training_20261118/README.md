# S3 扩大初态和动作幅值的 61/97 对照

本轮增加 36 对训练数据，完成了从 61 对到 97 对的固定 900 更新对照。模型结构、归一化、初始化、损失、Adam 和 S2 抽样序列均沿用原方案，种子为 20261111。开发轨迹只用于评分，测试轨迹封存，主模型保留，actor/critic 尚未训练。

## 采集范围

- 在第 72 和第 168 个控制周期分别取左、中、右三个独立训练初态。以 S1 球初始位置为参考，世界坐标 x 分别偏移 −6、+6 mm，y 偏移 −14、0、+14 mm。为避免初始穿入铲面，三条横向位置对应的 z 偏移为 +3、+17、+31 mm。六个球初态的最小静态间隙为 2.50 mm。沿用训练侧 Advance 控制历史，采集种子 2822306410。
- 每个快照回放两条名义轨迹，以及横滚、俯仰、双轴动作在 0.05 和 0.20 两档幅值下的正负扰动。动作在前 8 个控制周期施加，继续观察到 H32，即从快照向前 32 个控制周期。双轴的幅值按每轴计。每个训练初态六对，合计 36 对。
- 预检验证六个初态及 84 条分支。计算 54,528 个有效物理子步。保持单环境顺序执行，总实跑预算 3,000 秒，新输出 128 MiB，单进程工作集和私有提交上限为 2 GiB 和 3 GiB。启动可用 RAM 至少 2 GiB，运行低于 0.75 GiB 持续 2 秒停止。拟合独立使用 120 秒、32 MiB、1 GiB 工作集、1.5 GiB 私有提交和单线程 CPU。见 [采集命令及哈希](preflight.json)。

## 首组中断和续采

训练案 broad_train_72_left 采到 4,736 个已记录子步后，系统可用内存持续低于 0.75 GiB。开跑时可用 4.82 GiB，运行最低 0.416 GiB，Newton 进程峰值工作集 607.53 MiB。保留的两条名义轨迹和接触日志逐字节相同，快照及七条已完成分支通过离线检查。首组中断前完成两档横滚正负配对，H32 位置半差幅值分别为 0.066 和 0.209 mm。半差等于正扰动与负扰动的结果相减后除以二。见 [停止记录](stopped.json)、资源记录（本地归档） 和 [续采依据](../s3_world_increment_data97_partial_audit_20261118_verified/partial_capture_audit.json)。

用户授权从首组快照补跑 pitch_005_minus。此前该分支最多消耗 512 个未保存子步，累计硬上限相应为 55,040。续采重用 4,736 个已记录子步，只需执行原范围剩余的 49,792 个子步。见 [续采清单](resume_plan.json)。

续采完成六组和 36 对，合计归档 54,528 个有效物理子步。两段运行合计 33.59 分钟。续采期间最低可用 RAM 为 1.73 GiB，采集目录约 62.7 MiB。前后三个快照在实际铲面横向的跨度分别为 17.12 和 5.96 mm，两期在铲面纵向的跨度分别为 7.22 和 15.54 mm。见 [采集验收](validation.json) 和 [完整配对清单](capture_manifest.json)。

## 拟合核查

开训初始化和 S2 抽样哈希逐值复现。开训 S2 损失均为 0.0164094904，配对损失为 2.3436648562 → 4.6980953328，总梯度范数为 11.7381 → 21.6697，两个总梯度的方向余弦为 +0.666。97 对开训梯度用两个独立方向的中心差分核对，最大绝对差 1.00e−9。12 个初态组等权，每组占 1/12，原 61 对各组内部的相对权重沿用原方案。一次 900 更新及评分共 67.84 秒，峰值工作集 168 MiB，输出约 4.33 MiB。见 [开训核查](../s3_world_increment_data97_fit_20261118/fit_preflight.json)、[固定终点验收](../s3_world_increment_data97_fit_20261118/validation.json) 和 [拟合入口](../../scripts/train_s3_broad_data97.py)。

名义 H32 位置偏差从 4.310 增至 13.463 mm。相对原 61 对，22 项旧指标保护通过 17 项。五项退步涉及一个对角初态的方向、历史负 y 组的位置和方向、原负 y 组的位置和方向。短俯仰的联合响应、反向或双轴的联合响应及旧指标保护均有缺项。主模型继续保留。[准入记录](../s3_world_increment_data97_fit_20261118/validation.json)

扩大训练范围压下了纯横滚的幅值高估，也修正了原幅双轴的方向。该对照同时改变了训练初态、动作幅值的覆盖和旧组占比，结果无法归因到其中一项。下一轮先用两个固定终点和已归档轨迹定位名义漂移和俯仰响应退步集中在哪个阶段，再按新旧初态组和幅值拆开核对来自各组的训练梯度。
